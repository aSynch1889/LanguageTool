# LocaleDesk Technical SEO Design

**Status**: Implemented  
**Date**: 2026-10-22  
**Site**: https://localedesk.cc  
**Priority**: English / Google

## Scope

Technical SEO foundation only (no blog, no `/en`/`/zh` path split).

## Deliverables

- `robots.txt` with Sitemap pointer
- `sitemap.xml` for `/`, `/docs/`, `/privacy/`
- Per-page: canonical, Open Graph, Twitter Card
- Homepage JSON-LD `SoftwareApplication`
- Stronger English meta descriptions (natural keywords)
- Deploy to Cloudflare; GSC verification done by user after deploy

## Out of scope

- Content marketing / blog posts
- Baidu-specific optimization
- Separate crawlable Chinese URLs
