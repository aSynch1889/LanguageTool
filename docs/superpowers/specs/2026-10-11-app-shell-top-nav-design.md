# 设计：顶栏分段导航（去掉侧栏）

> 日期：2026-10-11  
> 状态：已确认（对话 §1–§3）；**已落地**（2026-10-11）  
> 前置：`2026-10-08-app-shell-sidebar-design.md`（方案 A 已落地）  
> 目标：消除仅含「转换 / 审阅」两项时的侧栏空白浪费，主内容全宽

---

## 1. 背景与问题

单窗口侧栏壳已落地：`NavigationSplitView` + 侧栏两项（转换、审阅），工具栏右侧为设置 / 语言 / 外观。

问题：侧栏只有两项，下方大片空白，信息密度低；审阅表格也被挤窄。用户确认采用 **去掉侧栏，改用顶栏分段切换**。

---

## 2. 目标与非目标

### 目标

1. 移除主壳左侧 sidebar 列；主 Detail 全宽
2. 用工具栏 **居中** 的分段控件（`Picker` / Segmented）切换「转换 | 审阅」
3. 保留右侧工具栏：⚙ 设置、🌐 语言、☀/☾ 外观
4. 跨页行为与现壳一致：转换成功进审阅、脏文档确认、空态「去转换」

### 非目标

- 顶栏/侧栏塞入最近文件、术语表、历史等新功能
- 重做转换页或审阅表格视觉
- Settings / Glossary 内嵌主窗
- 多窗口审阅、⌘1 / ⌘2（可后置）
- 改 AI 翻译管线

---

## 3. 信息架构与布局

```text
┌────────────────────────────────────────────────────────────────────┐
│ ● ● ●          [  转换  |  审阅  ]              ⚙   🌐   ☀/☾      │
│                  居中分段                         靠右操作          │
├────────────────────────────────────────────────────────────────────┤
│                                                                    │
│              Detail 全宽                                           │
│              · selection == .transfer → TransferView               │
│              · selection == .review   → LocalizationMasterView     │
│                                                                    │
└────────────────────────────────────────────────────────────────────┘
```

| 区域 | 内容 |
|------|------|
| 顶栏居中 | 分段：转换 / 审阅（绑定 `AppShellViewModel.sidebar` 或改名为 `selectedTab`） |
| 顶栏靠右 | SettingsLink、语言 Menu、外观 Menu（现有行为不变） |
| Detail | 现有 ZStack 保活两页，避免切换 remount |

不再使用 `NavigationSplitView` 的 sidebar 列（可改为单栏 `NavigationStack` / 普通根视图 + `.toolbar`，实现时选一种，优先少改动、工具栏可用性）。

---

## 4. 导航与跨页行为

与 `2026-10-08` 侧栏设计一致，入口从侧栏 List 改为顶栏分段：

1. **冷启动** → 默认「转换」
2. **转换成功** / 「在审阅中打开」→ 选中「审阅」并载入文档（`requestReview`）
3. **审阅空态「去转换」** → 选中「转换」
4. **脏文档**：从审阅切到转换前调用 `confirmCloseIfNeeded()`；取消则保持审阅选中
5. **快捷键 ⌘1 / ⌘2**：首版不做

---

## 5. 组件与职责变更

| 组件 | 变更 |
|------|------|
| `AppShellView` | 去掉 `NavigationSplitView` sidebar `List`；Detail 全宽；toolbar 增加居中分段 |
| `AppShellViewModel` | 选中态语义不变（可保留 `sidebar` 命名或 rename 为 `selectedTab`；rename 非必须） |
| `TransferView` / Master | 无行为变更；仅获得更宽布局 |
| 文案 | 侧栏「设置…」本就不在当前实现中；无需新增文案 key（分段继续用 Convert / Review） |

---

## 6. 测试与验收

- [x] 冷启动进入「转换」，无左侧侧栏列（`NavigationStack` + 顶栏分段）

- [x] ⚙ / 语言 / 外观行为与现网一致（toolbar 未改语义）

---

## 7. 已确认决策

- 方案：**去掉侧栏 + 顶栏居中分段**
- 右侧工具栏三项保留
- 导航/脏文档行为不变
- 首版不做快捷键与侧栏填充型功能
