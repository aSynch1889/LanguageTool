FAQ

Answers for developers evaluating LocaleDesk for iOS, Flutter, and Electron localization on Mac.

What is LocaleDesk?

LocaleDesk is a macOS localization app.

Which formats are supported?

.strings, .xcstrings, .arb, .json.

Do I need an API key?

Only for your own provider.

Do I need Xcode?

Not required to run the app.

Does localization stay on my Mac?

Yes by default.

What macOS version is required?

macOS 13.0 or later.

How is this different from spreadsheets?

Structure-preserving batch workflow with Review.

Where do I download LocaleDesk?

Mac App Store.
